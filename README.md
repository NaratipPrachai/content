# ระบบจัดการสื่อการเรียนรู้ (Media Learning Management System)

## 📋 ภาพรวมระบบ

ระบบจัดการสื่อการเรียนรู้นี้เป็น **Web Application** ที่พัฒนาด้วย PHP สำหรับองค์กรการศึกษา เพื่อจัดเก็บ จัดการ และแจกจ่ายสื่อการเรียนรู้ดิจิทัลแก่นักเรียน นักศึกษา และครูอาจารย์

## 🎯 วัตถุประสงค์หลัก

### 1. **จัดการสื่อการเรียนรู้ส่วนกลาง**
- เก็บรวบรวมสื่อการเรียนรู้ทุกประเภทไว้ในที่เดียว
- รองรับไฟล์หลากหลายรูปแบบ (วิดีโอ, PDF, Word, รูปภาพ, PowerPoint)
- เชื่อมต่อกับ Google Drive สำหรับจัดเก็บไฟล์ขนาดใหญ่

### 2. **ควบคุมสิทธิ์การเข้าถึง**
- จัดการสิทธิ์ตามแผนกและรายวิชา
- ป้องกันการเข้าถึงข้อมูลที่ไม่เหมาะสม
- ระบบ User Management แบบ Role-based

### 3. **เพิ่มประสิทธิภาพการเรียนการสอน**
- ค้นหาสื่อได้รวดเร็วและแม่นยำ
- จัดหมวดหมู่ตามสาขาวิชาและรายวิชา
- แสดงผลที่เหมาะสมกับทุกอุปกรณ์

## 🏗️ สถาปัตยกรรมระบบ

### **Frontend**
- **HTML5/CSS3** - โครงสร้างและการแสดงผล
- **Tailwind CSS** - Framework สำหรับ responsive design
- **JavaScript (Vanilla)** - การโต้ตอบและ UX
- **Font Awesome** - ไอคอนและสัญลักษณ์

### **Backend**
- **PHP 7.4+** - ภาษาโปรแกรมหลัก
- **MySQL/MariaDB** - ฐานข้อมูล
- **Session Management** - การจัดการ login และสิทธิ์

### **Storage**
- **Local Storage** - สำหรับไฟล์ thumbnail และ illustrations
- **Google Drive API** - สำหรับไฟล์สื่อขนาดใหญ่

## 👥 กลุ่มผู้ใช้งาน

### 1. **ผู้ดูแลระบบ (Admin)**
- เพิ่ม/แก้ไข/ลบสื่อการเรียนรู้

- ดูสื่อการเรียนรู้ตามสิทธิ์ที่ได้รับ
- ค้นหาและกรองสื่อ
- เข้าถึงเฉพาะแผนกและรายวิชาที่รับผิดชอบ

### 3. **นักเรียน/นักศึกษา** (เตรียมไว้สำหรับอนาคต)
- ดูสื่อการเรียนรู้ตามหลักสูตรที่ลงทะเบียน
- ค้นหาสื่อตามความต้องการ

## 🛠️ การติดตั้งและการใช้งาน

### **ความต้องการของระบบ**
- PHP 7.4 หรือใหม่กว่า
- MySQL 5.7 หรือ MariaDB 10.2+
- Web Server (Apache/Nginx)
- PHP Extensions: mysqli, gd, fileinfo

### **การติดตั้ง**
1. Clone หรือ download โปรเจค
2. ตั้งค่าฐานข้อมูลใน `db.php`
3. Import database schema
4. ตั้งค่าสิทธิ์โฟลเดอร์ `uploads/`
5. เข้าระบบด้วย admin account

### **การใช้งานเบื้องต้น**
1. เข้าสู่ระบบผ่าน `index.php`
2. Admin สามารถเข้า admin panel ได้
3. เพิ่มแผนก/รายวิชา/ผู้ใช้
4. อัพโหลดสื่อการเรียนรู้
5. กำหนดสิทธิ์การเข้าถึง

## 🎨 การปรับแต่งระบบ

### **เปลี่ยนธีม/สี**
แก้ไขใน `styles.php`:
```css
:root {
  --primary-color: #667eea;
  --secondary-color: #764ba2;
}
```

### **ปรับจำนวนรายการต่อหน้า**
แก้ไขใน `dashboard.php`:
```php
$allowed_per_page = [12, 24, 48, 96];
```

### **เพิ่มประเภทไฟล์**
แก้ไขใน `media_card_render.php`:
```php
$file_type_icons = [
    'video' => '<i class="fas fa-video text-red-500"></i>',
    'audio' => '<i class="fas fa-music text-green-500"></i>',
    // เพิ่มประเภทใหม่...
];
```

## 🆘 การแก้ไขปัญหา

### **ปัญหาที่พบบ่อย**
1. **ไม่สามารถอัพโหลดไฟล์ได้**
   - ตรวจสอบสิทธิ์โฟลเดอร์ `uploads/`
   - ตรวจสอบขนาดไฟล์ใน PHP config

2. **ไม่แสดงรูปภาพ**
   - ตรวจสอบ path ของไฟล์
   - ตรวจสอบสิทธิ์การอ่านไฟล์

3. **ระบบช้า**

   - เพิ่ม index ในตารางที่ใช้บ่อย
